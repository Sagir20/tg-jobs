# Агент поиска работы + Telegram-бот

## Что внутри

| Файл | Назначение |
|---|---|
| `config.psd1` | Критерии: страны, запросы, фильтры, оценка. Меняй здесь (или попроси Claude) |
| `search.ps1` | Поиск по LinkedIn, hh.ru, Arbeitnow → оценка → база `data/jobs.json` |
| `bot.ps1` | Telegram-бот, отвечает на команды |
| `lib.ps1` | Общие функции |
| `run_search.cmd`, `start_bot.cmd` | Запуск двойным щелчком |
| `secrets.json` | Токен бота и твой chat_id (создаёшь сам, никому не показывай) |
| `data/jobs.csv` | Вся база для Excel |
| `data/agent.log` | Журнал работы |
| `tracker.csv` | Ручной трекер откликов (статусы веди здесь) |

## Как агент оценивает вакансии

- 🟢 **A** — сильное совпадение: приводы/роботы/embedded + твои навыки, подходящий опыт.
- 🟡 **B** — стоит посмотреть: совпадение частичное или «на вырост».
- ⚪ **C** — отсеяно: нужен опыт 5+ лет, свободный немецкий/нидерландский, оборонка/БПЛА или слабое совпадение.

Требования (опыт, язык) проверяются по полному тексту вакансии. Перед откликом всё равно открой вакансию сам.

## Настройка бота (один раз, ~5 минут)

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** вида `123456789:AA...`. Это пароль от бота — не пересылай его никому (и в чат с Claude тоже).
3. Скопируй `secrets.example.json` в `secrets.json` и вставь токен вместо `ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER`.
4. Запусти `start_bot.cmd`. Открой своего бота в Telegram и напиши `/start` — бот ответит твоим **chat_id**.
5. Впиши chat_id в `secrets.json` (в кавычках), закрой окно бота и запусти `start_bot.cmd` снова.
6. Напиши боту `/help` — готово.

Бот отвечает **только** на твой chat_id, остальные сообщения игнорирует.

## Mini App в Telegram (работает без включённого ПК)

Поиск раз в день запускает GitHub Actions (10:00 по Пекину), результат публикуется на GitHub Pages, а в боте появляется кнопка **«Вакансии»** слева от поля ввода.

- Репозиторий публичный, но база и данные приложения **зашифрованы** (AES-256-GCM) ключом `data_key`. Без ключа на сайте видна только пустая страница и шифротекст.
- Ключ хранится только в секретах GitHub и в кнопке бота в твоём чате.
- Статусы (⭐ 📨 💬 🎉 ❌ 🙈) и заметки хранятся в облаке Telegram (CloudStorage) и одинаковы на телефоне и ПК.
- `secrets.json`, `tracker.csv` и папка `data/` в репозиторий не попадают (`.gitignore`).

Настройка (один раз):
1. На github.com: **New repository** → имя, например `tg-jobs` → **Public** → без README → Create.
2. В этой папке: `git remote add origin https://github.com/ТВОЙ_ЛОГИН/tg-jobs.git` и `git push -u origin main` (откроется окно входа в GitHub).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret** — три секрета из `secrets.json`:
   - `TG_TOKEN` — значение `token`
   - `TG_CHAT_ID` — значение `chat_id`
   - `DATA_KEY` — значение `data_key`
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. **Actions → Поиск вакансий → Run workflow**. Первый запуск ищет за 30 дней (~15–25 минут), потом бот пришлёт отчёт с кнопкой «Открыть приложение».

Если ключ утёк: сгенерируй новый `data_key` (попроси Claude), обнови секрет `DATA_KEY` и запусти workflow — старая база не расшифруется, поиск начнётся заново, а кнопка в боте обновится сама.

GitHub отключает расписание в публичном репозитории после 60 дней без активности — придёт письмо, достаточно нажать «Enable workflow».

## Команды бота (локальный бот, нужен включённый ПК)

- `/new` — новые вакансии, которые ты ещё не видел
- `/top` — лучшие (A и B) за 2 недели
- `/cn`, `/de`, `/nl`, `/ru` — по стране
- `/easy` — Сербия, Армения, Казахстан, ОАЭ, Кипр
- `/remote` — удалённые
- `/find ethercat` — поиск по слову
- `/search` — запустить поиск прямо сейчас (15–30 минут)
- `/stats` — статистика базы

## Если поменял критерии

После правки `config.psd1` пересчитай оценки всей базы (без повторного поиска):

```bat
powershell -ExecutionPolicy Bypass -File search.ps1 -Rescore
```

## Важно

- Бот и поиск работают, **пока включён компьютер**.
- Из Китая LinkedIn и Telegram доступны только через **VPN** — без него поиск по LinkedIn и бот работать не будут (hh.ru и Arbeitnow — будут).
- Отклики агент **не отправляет**. Подготовка резюме и писем под конкретную вакансию — в сессии с Claude, отправка — только после твоего подтверждения.
